# Airi

Chatbot AI. Nói chuyện bằng tiếng bạn đang dùng — tiếng Việt hoặc tiếng Anh.

Airi chạy trên Grok. Cuộc trò chuyện được lưu trên máy bạn, không cần tài khoản.

## Dùng thử

Mở app và gửi một tin, hoặc chọn một gợi ý ở màn hình đầu. Enter để gửi, Shift+Enter để xuống dòng. Bấm ô vuông để dừng câu đang viết.

## Mã nguồn

- Giao diện: `src/components/airi/`
- API chat: `src/routes/api/chat.ts`
